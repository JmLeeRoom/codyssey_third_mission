테스트 퀵 프리셋:

main.py의 mac() + judge_scores() 로직을 그대로 재현합니다. 숫자를 직접 수정하면 점수·판정이 즉시 갱신됩니다.

A 점수 S(P, FA) 1.0
B 점수 S(P, FB) 5.0
절대 차이 |A − B| 4.0
최종 판정 B (X 필터)
|A−B| ≥ 1e-9 이므로 더 높은 점수의 필터를 선택합니다.
🧮 핵심 수식 & 복잡도 언어

MAC 점수 = 두 행렬의 내적 (Dot Product)

S(P, F) = Σr=0..N−1 Σc=0..N−1 Pr,c · Fr,c

같은 위치의 원소를 곱해 전부 누적한다.
기준값: Cross·Cross = 5.0, Cross·X = 1.0 (3×3)

epsilon 동점 정책 (모드 1·2 공통)

|SA − SB| < 1e−9 → UNDECIDED

엄격한 미만(<) 비교의 절대 오차 정책.
차이 0.999e−9는 동점, 정확히 1.0e−9는 동점이 아니다.

일반 입력에서 필요한 정규화

cos θ = (P · F) / (‖P‖ ‖F‖)

스케일·노름이 다른 일반 입력은 코사인 유사도 등
정규화가 필요하다 (본 과제는 동일 스케일 0/1 템플릿).

N² · 2N² · O(N²) 정확히 구분하기

N² = 필터 1개와의 MAC 위치 수 (9 · 25 · 169 · 625) 2N² = Cross/X 전체 분류의 위치 수 (25×25는 1,250개) O(N²) = 상수·저차항을 지운 증가율 (이중 for 루프 구조가 근거) 625/169 ≈ 3.70 = 13→25 확장 시 고정 연산량 비율 (시간은 참고값)
